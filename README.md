# TIM ATIEP — Launch Presentation

Stage presentation site for the official launch of **TIM ATIEP (The Tree of Shade)**, a poetry collection by Adut Loi Akok, at Unipod Hall, University of Juba.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4 (theme tokens live in `app/globals.css` under `@theme`)
- Framer Motion for slide transitions
- Lucide icons (`lucide-react`)

## Structure

```
app/                 routes, root layout, global theme
components/stage/    full-screen presentation pieces (slides, speaker cards, gallery)
components/ui/       shared small UI elements
data/                typed content: presentationData.ts (event, book, speakers, milestones, poems, gallery)
public/images/       photos, book cover, speaker portraits (see its README for filenames)
```

## Theme tokens

Colours come from the book cover. Only these three are used; every other shade is mixed from them in `app/globals.css`.

| Token | Value | Use |
| --- | --- | --- |
| `indigo-base` | `#1B2B47` | background (deep blue) |
| `tree-red` | `#E53935` | the shade tree, text outlines, buttons, active elements, wood-grain texture |
| `clean-white` | `#FFFFFF` | titles and main text |

Derived shades: `indigo-raised` / `indigo-line` (panels, borders), `indigo-deep` (shadows), `tree-red-soft` (small red text, gradients) / `tree-red-deep` (hover, gradients), `clean-white-muted` / `clean-white-faint` (secondary text).

Every screen sits on `bg-cover-texture`: indigo with the swirling wood-grain from the cover's tree trunk as a tiled watermark (`public/textures/wood-grain.svg`). Behind every slide stands the cover's red shade tree (`components/ui/ShadeTree.tsx`), a silhouette generated by `scripts/generate-shade-tree.mjs` and painted with `tree-red` plus wood grain. If you change the red, also update the colour numbers in `public/textures/wood-grain.svg`. Critical headers use `text-cover-title` (cover white with a thin red outline).

Stage type scale (viewport-scaled): `text-stage-hero`, `text-stage-title`, `text-stage-heading`, `text-stage-lead`, `text-stage-body`, `text-stage-label`, `text-stage-small`. Fonts: `font-display` (Playfair Display) for titles and poetry, `font-sans` (Geist) for everything else.

## Routes

| URL | View |
| --- | --- |
| `/` | Stage presentation. Phones are redirected to `/mobile` (see `proxy.ts`). |
| `/stage` | Stage presentation, always — use this on the projector laptop. |
| `/mobile` | Attendee guide: scrollable event overview for phones. |

The welcome slide shows an **Event guide** QR code that opens `/mobile`. Set `NEXT_PUBLIC_SITE_URL` to the deployed address (e.g. `https://tim-atiep.vercel.app`) before building, otherwise the QR points at whatever address the stage laptop is using — and `localhost` is unreachable from phones (the slide warns when that's the case).

## Screen sizes

Stage type scales with the smaller of screen width and height, so 16:9, 16:10, 4:3 and ultrawide projectors keep the same proportions. Above 1920×1080 the whole stage (controls included) scales up, so 4K looks like 1080p, only sharper. The attendee view is a single mobile-first column, centred on larger screens.

## Stage controls

| Key | Action |
| --- | --- |
| → / Space / Page Down | Next slide |
| ← / Page Up | Previous slide |
| Home / End | First / last slide |
| ↑ / ↓ | Previous / next speaker, poem or photo (Speakers, Poems and Gallery slides) |
| 1–9 | Jump to speaker N (Speakers slide) |
| P | Pause / resume the gallery |
| F | Toggle full screen |
| M | Toggle ambient sound |
| Esc | Close popups |
